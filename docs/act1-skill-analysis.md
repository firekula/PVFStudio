# ACT1 代表技能逐项分析

使用同一套 ACT1 `Script.pvf` 与 `ImagePacks2` 核对资源和解码帧。下列时间以 Lv1、基础施放速度、水平朝向和无障碍的离线预览为准。

## 擒月炎

格斗家技能 3 进入状态 23，使用 CHR 扩展动作 14 的 `GrabExplosion.ani`。原 ANI 第 8 帧的 10000 ms 是等状态反馈的占位时间。

| 时刻 | 动作与特效 |
| --- | --- |
| 0–550 ms | 伸手抓取，播放原动作帧 0–7。 |
| 550 ms | 抓空回待机。抓中时跳到动作帧 9，在角色原点挂载 `GrabExplosion1/2/3.ani`。三个光效层按顺序绘制在角色上方。 |
| 550–650 ms | 角色和蓄火层向前移动 50 px。初速为 1000 px/s，减速度为 10000 px/s²。 |
| 1590 ms | 动作帧 13 移除蓄火并生成对象 21014。生成点相对移动后的角色为前方 59 px、地面 Y−1、离地 94 px。 |
| 2390 ms | 角色回待机，已经生成的粒子继续消散。 |

21014 的基础 ANI 只有攻击判定。可见爆炸来自对象引用的四组 `FireExplosionParticle*.ptl`。四组一起开始，原发射频率分别为每秒 5、20、100、10 个，粒子寿命分别为 500、700、700、1000 ms。爆炸图像和运动参数按等级表第 3 列缩放，原点保持一致。

预览默认演示抓中。效果下拉框可切换“擒月炎 · 未抓到目标”。目标的实际被抓姿态和高度随目标变化，本版画布省略目标模型。

原生依据为 `0x5E9C90`、`0x5E39C0`、`0x5DF700`、`0x4C8C00`、`0x5C2160`、`0x5C27E0`。

## 怒气爆发

鬼剑士技能 24 使用状态 10。按施放参数选择 CHR 第二组投掷动作 `Summon1.ani` 和 `Summon2.ani`，初段 400 ms，收招 700 ms。地面效果从施放开始独立计时。

| 对象 | 绘制与触发 |
| --- | --- |
| 20009 | 在角色地面 Y+50 合成血阵和血柱。`BlastBloodFloor1/2/3` 在地面层绘制且保持纹理方向。`BlastBlood2/1/3` 按后、中、前顺序绘制并随角色翻转。 |
| 20031 | 在角色原点依次播放施放后层和前层。第一张可见图像在 100 ms 出现，400 ms 结束。 |
| 20010 | 在角色原点生成隐形外围攻击判定，1120–1360 ms 生效。实际命中符合条件的地面目标时，才会在目标处生成受击血花。 |

血阵从 0 ms 可见，400 ms 增加暗纹，960 ms 开始变亮，**1200 ms 开始喷发**。中心血柱自身的攻击框在 1200–1440 ms 生效，和外围对象使用独立的帧时钟。最晚的地面图层在 2240 ms 结束。施放结束后的地面动画继续播放。原包的 `BlastBlood2.ani` 声明 14 帧，实际有 15 帧，预览沿用解析器的实际帧顺序。

原生依据为 `0x638640`、`0x643D00`、`0x49EB50`、`0x590420`、`0x590740`、`0x5907C0`。施放阶段由原生状态时长确定，身体各帧保留 ANI 的配置时长。

## 十字斩

鬼剑士技能 64 使用状态 31。游戏说明中的前两道刀光挂在角色身上。身体进入第 6 帧后进入待发射阶段，第二道刀光结束才生成对象 20028。原包在 590 ms 发出飞行血十字，起点在角色前方 85 px、离地 82 px。前后两层共用 `GoreCross.ptl` 的减速轨迹，280 ms 内从 400 px/s 降到零，前行 56 px 后消失。出血与命中反应需要目标。

原生依据为 `0x638640`、`0x643D00` 和 `passiveobject/swordman/gorecross.obj` 中的动画结束销毁条件。

## 念气波

格斗家技能 12 使用第二组投掷动作 `Throw1.ani` 和 `Shoot.ani`。两个阶段分别在角色原点挂载 `EnergyCharge.ani` 和 `EnergyBallShoot.ani`。

- 默认聚气 250 ms，出手特效第 0 帧时长 70 ms。在 **320 ms** 进入第 1 帧后，生成对象 21002。
- 出球位置为角色前方 70 px、离地 63 px。球体使用对象的 `EnergyBall.ani`，按 PTL 的 400 px/s 水平前进。左右朝向会同时改变贴图和飞行方向。
- Lv1 球体原始尺寸为 100%，飞行 525 ms。Lv30 为 200%，飞行 1150 ms。等级变化可从时间轴和飞行距离直接看到。
- 命中时的 21003 使用透明攻击盒。本版播放无目标飞行，聚气身体的五个原始姿势按配置的施放时长等比压缩，基础施放时五帧各 50 ms。

原生依据为 `0x5E9C90`、`0x5E39C0`、`0x4A86B0`、`0x5999D0`、`0x599A60`。

## 螺旋念气场

格斗家技能 16 使用状态 10 和第二组投掷动作。施放开始时播放 `Throw1.ani`，同时挂载循环的 `EnergyCharge.ani`。700 ms 后切到 `Shoot.ani` 推掌动作，在前方 107 px、地面 Y+1、离地 62 px 生成对象 21006。

对象使用 `EnergyField.ani`，16 个可见帧各 65 ms，持续 1040 ms。大小取技能等级表第 5 列，原包 Lv1 为 100%。预览采用基础施放时长和原始动作帧时长。实际命中的连击、感电和受击表现需要目标。

原生依据为 `0x5E39C0`、`0x5E9C90`、`0x4A86B0`、`0x599B60` 和 `0x599C20`。

## 魔法星弹

魔法师技能 11 使用第一组投掷动作和 `OneHandThrow1/2.ani` 特效。短按时在 **420 ms** 出手，直接在前方 44 px、离地 60 px 生成对象 23007。默认水平速度为 400 px/s。Lv1 生命时长 520 ms，940 ms 结束飞行。角色收招 300 ms，飞行期间可切回待机。

本版演示短按、水平飞行和左右镜像。蓄力、方向键角度、追踪和尾迹仍待接入。原生依据为 `0x6103F0`、`0x614D40`、`0x55BDE0`。


## 魔法护盾

魔法师技能 37 进入 Buff 施放状态 14，Lv1 在 1000 ms 生效。Buff 生效图标来自原生 BuffIcon 第 32 帧。护盾用 `AuraShieldStart.ani` 展开，160 ms 后切到 `AuraShieldLoop.ani`，沿角色原点继续绘制。维持动画截取 1.8 秒，受击与消失分支在实战条件满足时触发。原生依据为 `0x614D40`、`0x613CF0`、`0x544B70`、`0x544A90`。

公共 Buff 的聚气光球和粒子使用角色世界 X/Y，Z 为角色高度加 30 px。预览从待机身体首帧的 ANI 坐标、缩放和 IMG 裁切偏移求出高度。原始资源中魔法师为 84 px，神枪手为 127 px，聚气锚点分别在地面上方 114 和 157 px。首个增益的生效图标和粒子也使用该头顶锚点。后续的维持特效按技能挂点绘制，例如魔法护盾使用角色原点，远古记忆的粒子使用半身高度。坐标依据为 `0x82C630`、`0x4A1559`、`0x49FB72`、`0x505C20` 和 `0x52B810`。

## 炫纹强压

魔法师技能 10 使用状态 24 和 CHR 扩展动作 8。Lv1 在 160 ms 起跳，480 ms 到达 70 px 高度并聚合。原动作第 6 帧用于等待施放状态，停留按 SKL 的 1000 ms 配置。1480 ms 下砸，1640 ms 在前方 77 px 生成对象 23030 的地面冲击与爆炸。聚合和冲击的高度、距离及倍率读取 `data/skill/mage.sd`。

默认使用三枚普通无属性炫纹演示，按实际炫纹数量逐次改变聚合和爆炸大小。预存炫纹的数量和属性在游戏里取决于角色此前的操作。原生依据为 `0x6103F0`、`0x614D40` 及 CNChaser 聚合状态。

## 湮灭黑洞

魔法师技能 58 使用第二组投掷动作。Lv1 在 1500 ms 施放，生成对象 23025。中心位于前方 200 px、离地 80 px，读取 `data/skill/mage.sd`。地面投影绘制在高度 0。

| 时刻 | 画面 |
| --- | --- |
| 1500–2300 ms | 黑洞成形，涡流从 2060 ms 起扩张。 |
| 2300–4100 ms | 涡流、电光、核心和地面投影维持。 |
| 4100 ms | 开始播放爆裂预兆。 |
| 4500 ms | 按等级持续时间切换到爆裂阶段。 |
| 4780 ms | 开始发射爆裂粒子，黑洞对象消散后粒子继续。 |

Lv20 的爆裂阶段从 6500 ms 开始。预览采用地下城时序，目标吸附和受击由实战处理。原生依据为 `0x6103F0`、`0x614D40`、`0x5ADC80`、`0x5AD830`、`0x5ADE80`。

## 煌龙偃月

魔法师技能 69 使用状态 25 和 CHR 扩展动作 17。Lv1 先播放 `SpearAttack1/2/3`，1760 ms 进入持刀阶段。角色身体第 10、11 帧使用同一张图，原装扮层止于第 10 帧。持刀期间沿用第 10 帧的可见图层和第 11 帧对应的触发时序。

| 分支 | 画面 |
| --- | --- |
| 命中示例 | 刀尖周围生成七组龙之炫纹。第一个炫纹在 2260 ms 爆炸，其余依次触发对象 23031。3500 ms 播放对象 23032 的三层最终爆炸，3800 ms 开始消散。 |
| 未命中 | 1760 ms 直接播放收刀消散，2400 ms 结束。 |

预览采用原生的刀尖参考点，位于角色前方 322 px、离地 43 px。炫纹的角度顺序和爆炸偏移使用一组可复现的随机样本，便于回拖比对。目标被推至刀尖的过程依赖实战对象。原生施放和资源关联依据为 `0x6103F0`、`0x614D40`、`data/skill/mage.sd` 和被动对象 23031、23032。

## 后跳

五职业的技能 169 进入共用跳跃状态 6 的后跳分支，使用职业 CHR 跳跃动作中着地前的空中帧，落地后跳转到收招帧。原生水平速度为 286 px/s，朝角色面向的反方向。以默认跳跃力和普通地面演示时，约 538 ms 落地，退约 154 px。落地粒子从实际落点发出，角色回待机时会保留落地位置。

原生依据为 `0x49EB50`、`0x48A460`、`0x488FE0`、`0x4895A0`。预览使用基础重力和默认角色能力，普通地面扬尘取 `DustDownSmall.ptl`。

## 其他 Buff

- 五职业均核对了跃翔、远古记忆、不屈意志，共 15 个技能条目。共用技能处理函数 `0x49A9F0` 读取职业技能目录和各自的 BuffIcon。
- 职业技能核对了强拳、破极兵刃、暴走、缓慢愈合、快速愈合、武器祝福和天使祝福。破极兵刃的持续 PTL 在该包中缺失，保留施法和生效阶段。
- 施法阶段和生效特效按各自的脚本与原始 ANI 时序播放。可选目标的祝福和治疗以施法者为示例，持续动画截取约 1.8 秒。Buff 图标最初的原生单色处理、武器祝福的持续武器染色仍待还原。

## 空绞锤、背摔与螺旋彗星落

三个技能分别提供普通目标抓中和未抓到的演示。空绞锤使用状态 28/29 和 CHR 扩展动作 18/19。以 50 px 参考高度抓中后播放闪光和翻转，接着下落。Lv1 示例在 550 ms 触地，生成原始落地光效和对象 21016，冲击点在角色后方 28 px。600 ms 后角色反弹，抓空时改为自然落地。

背摔和螺旋彗星落使用状态 17/18。背摔在成功动作第 4 帧生成对象 21001 的落地扬尘。螺旋彗星落有离地、前后回旋光效和对象 21008 的两层冲击。施放速度、初始高度和方向采用演示参数。受抓目标的身体、抗抓踢击及命中伤害仍依赖实战。

## 地裂、冰刃与爆炎波动剑

鬼剑士状态 20 使用 `Wave.ani`。地裂在角色第 3 帧生成对象 20001，横向推进来自对象自身 ANI。冰刃和爆炎在第 4 帧释放。冰刃按等级决定冰柱数，原包每隔 100 ms 生成一柱，并绘制烟雾、碎冰与星光。爆炎先播放双层火浪，在前方 360 px 续接爆炸。预览以未按方向键和阿修罗的火浪尺寸演示。依据为 `0x638640`、`0x643D00` 和对象 20001、20002、20024、20025 的更新逻辑。

## 爆头一击、回头一击与浮空弹

神枪手状态 8 使用实际枪械的拔枪、出弹和收招时间。普通分支向前射击，效果列表可选择向下射击。回头一击在起手时反转角色、枪口和弹道。手炮的弹道对象只带攻击盒，枪口光效仍可见。预览应用职业基础攻速和当前武器参数，回头一击以关联的爆头一击 Lv1 演示。依据为 `0x600690`、`0x5F9CB0`、`0x5F37F0` 和 `etc/gunnerdefaultguninfo.etc`。

## 魔法师五种蓄力投射物

杰克爆弹、冰霜雪人、雷光珠、暗影夜猫、虚无之球均支持自动短按和手动选择满蓄力。第三组 CHR 动作对应雷光珠，第四组对应冰霜雪人，装扮层随身体一起切换。杰克爆弹用射程末端的示例碰撞触发爆炸。雪人演示无目标时的跳跃与落地，雷光珠用原始 PTL 曲线绕身扩散，夜猫前扑再返回，虚无之球持续前移并在到期后淡出。追踪、命中及输入改变方向由实战处理。

## 圣职者的施法动作与效果

客户端从 0 开始索引四组投掷动作。模式 1 对应 Pray，模式 2 对应 Deliver，模式 3 对应 Blast。原有武器祝福、缓慢愈合、快速愈合和天使祝福已切到 Deliver。新接入的施放包含以下原始对象与图层。

- 化魔、天籁之音、守护徽章、生命源泉、光之复仇、天堂谐音、圣愈之风、荣誉祝福和净化按各自的施放阶段切换角色和光效。部分增益以施法者为示例目标。净化结果、复苏和落雷需要对应的异常状态、生命值或攻击条件。
- 圣光守护播放出现和维持，烈焰与寒冰脉轮绘制各自的三层前景和三层后景。持续阶段取约 1.8 秒。
- 圣光沁盾前进并在到期前淡出，圣光球飞行、预警并爆炸，破魔符播放原始放飞与爆炸。恶魔之手按原版出手点生成对象 24003 和其两层附加光效。
