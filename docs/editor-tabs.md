# 编辑器标签页与菜单

0.8.0 使用固定顺序的单行标签栏。标签超出宽度后通过两端按钮滚动，切换不会再把多行中的选中行移到底部。再次从目录或搜索打开同一文件只激活原标签，保留文档、光标和未保存内容。拖动标签或使用移动命令才会调整顺序。

标签带文件图标、未保存标记和关闭按钮，中键也可关闭。右键菜单以鼠标所指标签为目标，包含保存、关闭、关闭其他/左侧/右侧/未修改标签、全部关闭、左右移动、重新打开及复制 PVF 内路径。打开右键菜单不会先切换编辑器。

## Windows 快捷键

采用 [VS Code Windows 快捷键](https://code.visualstudio.com/shortcuts/keyboard-shortcuts-windows.pdf) 与 [默认快捷键参考](https://code.visualstudio.com/docs/reference/default-keybindings) 中的相关组合。`Ctrl+K Ctrl+W` 表示先按一组，再按后一组。

| 操作 | 快捷键 |
| --- | --- |
| 关闭当前标签 | Ctrl+W / Ctrl+F4 |
| 按标签位置切到前一个/后一个 | Ctrl+PageUp / Ctrl+PageDown |
| 按最近使用历史切换/反向切换 | Ctrl+Tab / Ctrl+Shift+Tab |
| 将当前标签向左/右移动 | Ctrl+Shift+PageUp / Ctrl+Shift+PageDown |
| 重新打开关闭的标签 | Ctrl+Shift+T |
| 全部关闭 | Ctrl+K Ctrl+W（单组也支持 Ctrl+K W） |
| 保存当前标签草稿 | Ctrl+S |
| 保存所有标签草稿 | Ctrl+K S |
| 复制当前文件的 PVF 内路径 | Ctrl+K P |

Ctrl+Tab 的最近使用历史与标签位置分别维护。按住 Ctrl 连按 Tab 可遍历一次历史列表，松开 Ctrl 后确认选择；不会改变标签的排列。Ctrl+PageUp/PageDown 按可见排列顺序切换。

关闭时只询问将被关闭的标签；选择保存只保存这些标签，不影响其余未保存编辑。取消保持标签和内容不变。关闭未修改标签以最近保存的草稿为基准，已保存草稿继续保留。

当前包内保留最近 100 个关闭标签的路径、位置、编码、光标和滚动位置，重新打开读取最后保存的草稿或原包；明确放弃的未保存内容不会被恢复。切换 PVF 后清空该历史。标签关闭或恢复都不会自动导出 PVF。

## 顶部菜单与最近文件（0.10.0）

顶部菜单栏提供“文件、编辑、选择、查看、转到、帮助”。文件菜单包含打开 PVF、最近文件、保存当前/全部草稿、导出、自动备份选项、打开编码、关闭编辑器和退出。编辑菜单使用当前 IntelliJ 编辑器的撤销/重做、剪切/复制/粘贴与查找/替换；选择菜单提供全选及扩大/缩小选择。查看菜单可显示差异、切换资源预览、自动换行和行号；转到菜单可定位路径搜索或切换编辑器。

“打开最近的文件”列出最近成功打开的 15 个 PVF 的完整路径，最近使用的排在前面，同一路径不重复。记录位于用户目录 `.pvf-studio/recent-files.properties`，通过后台原子替换保存；关闭窗口前完成最后写入。打开记录仍经过未保存编辑提示，成功后恢复该 PVF 的会话。丢失或暂时离线的路径保留，点击时显示打开错误，当前包继续保持。清空记录只移除列表，不关闭当前编辑器、不删除草稿和会话。

| 操作 | 快捷键 |
| --- | --- |
| 打开 PVF | Ctrl+O |
| 展开最近文件 | Ctrl+R |
| 定位路径搜索 | Ctrl+P |
| 查找 / 替换 | Ctrl+F / Ctrl+H |
| 剪切 / 复制 / 粘贴 | Ctrl+X / Ctrl+C / Ctrl+V |
| 全选 | Ctrl+A |
| 扩大 / 缩小选择 | Shift+Alt+Right / Shift+Alt+Left |
| 自动换行 | Alt+Z |

## 自动恢复会话（0.9.0）

每个 PVF 的草稿工作区内增加 `editor-session.properties`，记录打开的标签、视觉排列、当前选中标签，以及各标签的编码、光标偏移、横向和纵向滚动位置。工作区按源路径和源包内容摘要隔离。重新打开同一原包时自动读取已保存草稿或原文，并按会话恢复编辑器，无需先打开某个标签。

标签切换、移动、打开/关闭、光标移动或滚动后，空闲 650ms 合并保存一次；关闭窗口、切换 PVF 前完成最终写入。磁盘操作在后台执行，临时文件刷新后原子替换旧会话。保存失败保留窗口并提示，可重试关闭或切换。恢复或释放编辑器期间暂停自动记录，避免暂时的空标签覆盖原状态。

尚未显示的标签先保留目标滚动位置，首次选中并完成布局后应用；在此之前再次关闭程序，位置仍会保留。正文变短时光标截断到末尾，滚动由编辑器约束到可见范围。找不到条目、无效编码或损坏会话会跳过并在状态栏提示；其他有效标签继续恢复。主动关闭全部标签会保存空状态，下次不再打开旧标签。

会话不包含正文，不会代替 Ctrl+S 保存草稿。关闭窗口选择“放弃未保存编辑”仍保留标签和位置，但重开只读取最后保存的草稿或原包；选择取消则保持当前窗口。关闭历史及撤销历史仍只属于当前运行会话。
