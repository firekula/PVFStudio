# PVF 导出修复：0.14.7

导出选择框现在只显示 PVF 类型，未填写后缀时补齐 `.pvf`，拒绝其他后缀并保留选择框供修改。默认文件名为 `Script-edited.pvf`。已有导出文件仍按原流程确认、备份后更新，当前打开的原始源文件保持只读。

原来的源校验要求文件标识和修改时间与打开时完全相同，因此，即使内容没有变化，元数据变化也会让所有目标导出失败。此次改为同时验证原始打开句柄及当前路径文件的完整 SHA-256，并要求校验过程中大小、类型、文件标识和修改时间稳定。真实内容变化仍阻止导出；打开时的严格校验、源路径/硬链接保护、暂存验证、备份及发布保护保留。

用户当前源文件 SHA-256 与保存工作区的基准一致：`5fcd4b94dfb081294701f7288345fff6ca5586d780fcc7130e4614c237eb6ad1`。当前文件的创建时间晚于旧程序的打开时间，结合报错，符合元数据变化而当前内容一致的情形；未修改或关闭用户正在运行的程序，也未修改用户源文件或草稿。此项证据不能代替对旧进程内句柄的直接校验，新版本在自己的验证中分别检查句柄与当前路径。
