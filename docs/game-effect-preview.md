# 装备、装扮和技能效果预览（0.15.0 本地开发版）

## 操作

打开 ACT1 PVF 的 `.equ`、`.skl` 或 `.stk` 时，主区默认显示“效果预览”。左侧继续使用文件树与搜索，中央为实际游戏资源组成的角色，右侧切换“游戏说明 / 穿戴搭配 / 资源”，底部提供播放、逐帧、倍速、循环和时间轴。

首次点击“选择资源目录”，关联同版本客户端或 ImagePacks2。图标和动画均按需读取 NPK/IMG，不需要解包或运行游戏。每个 PVF 工作区独立绑定资源目录；新打开的 PVF 不直接消费上一个工作区的资源索引。

- “代码 / 分屏 / 效果预览”共用现有文档，保留保存草稿、差异和撤销。
- 修改顶层装备、技能或已打开的 CHR/LAY/ANI/STR 依赖后，预览读取未保存快照；其次读取草稿和原包。
- “穿戴搭配”从当前 PVF 的适用职业装备、装扮及称号中按路径筛选。可以隐藏部位或重置；打开新物品时，其所属槽优先显示新选中的物品。
- “角色视角”保持角色可见。要查看激光全长等大范围效果，选择“全效果”；也可用滚轮缩放、拖动画布，或选择 100% / 200% / 400%。
- 主文件的职业有限定时固定职业；共用物品可以切换五职业。动作列表取自当前 CHR，并提供基础动作的中文名称。
- 带技能等级的说明会随选择更新。显示的是 PVF 基础配置，不含实例随机品级、强化和角色/装备的最终修正。范围值保留“配置范围”；部分尚未转换的单位标明“原始值”。

职业、手动动作、各职业搭配、各文件技能等级和效果选择保存到当前工作区的 `game-preview.properties`。播放位置、朝向、缩放和倍速属于本次窗口的临时状态。预览设置不修改 EQU/SKL，也不因为播放、搭配或等级选择制造脚本草稿。

## 本版支持范围

| 类型 | 已实现 | 精度与限制 |
| --- | --- | --- |
| ACT1 玩家穿戴 | 五职业默认身体/装扮、当前部位替换、variation、重复 include、多部件层序及 hide layer；基础动作 | 当前支持已识别的 CHR/EQU/LAY 规则。未知引用、循环和缺失图像显示诊断 |
| 护甲和首饰 | 图标、名称、本地化说明、基础属性及范围 | 没有穿戴视觉字段时明确显示参考角色，不凭物品名字生成外观 |
| 称号 | custom animation 与角色同时播放；角色左向时称号不反转 | 头顶锚点按角色可见边界对齐，尚未完成原生逐像素对照 |
| 激光炮 | 普通/满蓄力组合；身体、激光炮枪体、枪口、起始/平铺/末端；配置延迟与射程联动 | 使用 ACT1 原生资源关联、位置和 50px 平铺规则。满蓄力按被动技能 Lv.1 的配置演示；不模拟攻速修正、按键释放、伤害或命中 |
| 杰克爆弹 | 技能到原生对象 23008 的关联、初始视觉及独立关联动画片段 | 尚未组合完整施放、飞行、命中及爆炸流程 |
| 吞日者 | 原 EQU 的 if/then、概率、消耗和对象关联；23008 与 48030 的初始/关联动画 | 对象坐标取配置；不执行概率判定、目标选择、飞行/落地或战斗触发 |
| 其他技能/物品 | 图标、说明、直接 ANI/PTL 与已识别被动对象引用，职业动作检查 | 没有已验证配方时明确提示；预加载图片不会被伪装为完整施放流程。PTL 可继续在代码模式的原资源面板播放 |
| 其他 PVF 容器 | 原有代码及直接资源、地图/副本预览 | 不自动应用 ACT1 玩家/技能配方 |

本版不执行游戏战斗系统。资源能够解析、离线图像能够绘制和完成原生动态对照属于不同证据，验收报告分别记录。

## 检查命令

```powershell
$env:JAVA_HOME = 'C:\path\to\jdk-25'
.\gradlew.bat check -PwithIntellij=true :pvf-product:test :pvf-product:assembleProduct
python -B -m unittest discover -s validation -p 'test_*.py'
python -B tools/check_product.py --product pvf-product/build/product/PVFStudio-0.15.0 --archive 'C:\Game\Script.pvf' --npk 'C:\Game\ImagePacks2' --game-preview
```

`validation/GamePreviewAudit.java` 使用相同的解析和渲染器，生成实际资源的五职业及代表物品/技能帧；要求显式输入和新的输出目录。便携构建继续使用 `tools/build-release.ps1 -ZipOnly`，不包括游戏资源。
