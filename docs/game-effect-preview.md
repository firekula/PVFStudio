# 装备、装扮和技能效果预览（0.15.26）

## 操作

打开 ACT1 PVF 的 `.equ`、`.skl` 或 `.stk` 时，主区默认显示“效果预览”。左侧继续使用文件树与搜索，中央为实际游戏资源组成的角色，右侧切换“游戏说明 / 穿戴搭配 / 资源”，底部提供播放、逐帧、倍速、循环和时间轴。

首次点击“选择资源目录”，关联同版本客户端或 ImagePacks2。图标和动画均按需读取 NPK/IMG，不需要解包或运行游戏。每个 PVF 工作区独立绑定资源目录；新打开的 PVF 不直接消费上一个工作区的资源索引。

- 左侧目录树和路径搜索结果中，鼠标在装备、装扮、物品或技能上停留约 0.4 秒即显示游戏说明。选择资源目录后可显示配置图标，技能悬停按 Lv1 显示。
- “代码 / 分屏 / 效果预览”共用现有文档，保留保存草稿、差异和撤销。
- 修改顶层装备、技能或已打开的 CHR/LAY/ANI/STR 依赖后，预览读取未保存快照；其次读取草稿和原包。
- “穿戴搭配”从当前 PVF 的适用职业装备、装扮及称号中按路径筛选。可以隐藏部位或重置；打开新物品时，其所属槽优先显示新选中的物品。
- “角色视角”保持角色可见。要查看激光全长等大范围效果，选择“全效果”；也可用滚轮缩放、拖动画布，或选择 100% / 200% / 400%。放大含光效的画面时，预览先按游戏像素尺寸混合，再放大已合成的像素。
- 主文件的职业有限定时固定职业；共用物品可以切换五职业。动作列表取自当前 CHR，并提供基础动作的中文名称。
- 游戏说明按 ACT1 截图排版。客户端使用 SimSun（宋体），说明框按参考图的显示尺寸以 16 像素绘制。技能名后显示等级，施放时间与 MP 同行，冷却按秒显示。装备说明分为重量、类别、基础属性和效果。说明内容取当前 PVF 配置。
- 打开已关联的技能会自动播放并切到“全效果”。已确认的组合优先，其次播放脚本明确关联的 ANI/PTL，或唯一同名的 CHR 动作。未关联的技能在画布中显示原因。选择“仅角色动作”可查看职业动作。
- 播放栏的「判定框」默认只显示当前帧的角色受击框、攻击框及场景内敌人的受击框。单击一个框会暂停在该帧，并显示框的相对 X、Y、Z 和宽、深、高。连续单击重叠区域可在框之间切换，单击空白或调整播放进度取消选择。「框坐标」可同时显示所有框的数值。框的八个顶点按客户端 X、Y−Z 投影，与画面共用坐标。普通及聚焦喷火器包含独立攻击对象，怒气爆发包含中心血柱和外围攻击对象各自的生效帧。
- 霸体描边跟随当前身体帧和已核实的技能状态。渲染使用原版颜色节奏，身体与挂载的穿戴层共同参与描边。

## 命中、蓄力与武器条件

- 伏虎霸王拳、BBQ、踏射、裂波斩、虎袭和圆舞棍的效果菜单可切换到落空场景。伏虎霸王拳还可查看异常状态目标的狂·霸王拳分支。命中演示使用普通哥布林时，目标反应由预览时间轴播放。
- 破军升龙击可切换巨剑和钝器的蓄满砸地。三段斩可切换精通等级达到原包门槛时的太刀和光剑五段斩。选择分支会同步更换试用武器。
- 拔刀斩的太刀追击为红色，光剑追击为白色。两项选择演示精通和追击输入，并试用对应武器。鬼斩和噬灵鬼斩的效果菜单均可查看满蓄后的卡赞、萨亚和普戾蒙。
- 技能未指定穿戴武器时使用职业默认武器。选择“武器 · …”会试用同类最低装备等级的武器，再按武器选择原版动作和特效。回到自动技能动画时恢复当前搭配。
- 波动刻印和不动明王阵可选择一至五枚印记。不动明王阵和邪光波动阵的命中场景使用一名普通哥布林展示目标拘束。
- 激光炮可切换未学蓄电、学后短按和满蓄力。从蓄电激光炮或修罗邪光斩的被动条目打开效果预览，可直接播放满蓄力发射。
- 角色的 EQU 优先级低于零时画在身体后方，零或正值画在身体前方。快速愈合以施法者为示例受术者，光效位于脚底上方约 60% 身高处。
- 星落打默认展示抓取、蓄力、挥击和冲击，狙击枪默认展示命中后的延时爆炸。两项可在效果菜单中选择落空。
- 鬼影闪、鬼印珠、砖袭、寸拳、毒影针、武神强踢、野蛮冲撞、闪电之舞和抛投默认展示小怪命中。用效果下拉菜单可选择空场或未命中。武神强踢还可查看破招命中。挑衅会在范围内目标头顶显示标记。
- 幻影爆碎默认演示分身与目标接触后的光爆，可切换无接触。死亡毒雾的火属性分支从一枚地雷开始，按攻击盒相交和各自引信演示连锁。精灵献祭可查看单属性、四属性同次献祭和雷沃斯多目标落雷。
- 空投可单独演示四种稀有机器人。召唤兽菜单可选择具体攻击和支援招式，或切回仅召唤；招式说明列出原版 AI 的相关条件。
- 冥焰之卡洛、瘟疫之罗刹、星落打、光之复仇、落雷符和盖波加之拳的默认场景包含目标。冰霜雪人、魔力印记、鞭挞和落花掌可在效果菜单选择命中场景。魔法盾可切换到被哥布林攻击时的受击场景。
- 灵魂牺牲以倒地触发和一名范围内队友为例。幻影化身以一记直拳冲击展示 PVF 配置的影子延迟。空投、连续输入、目标数量及随机落点等使用可重复的参考场景。

职业、手动动作、各职业搭配、各文件技能等级和效果选择保存到当前工作区的 `game-preview.properties`。播放位置、朝向、缩放和倍速属于本次窗口的临时状态。预览设置不修改 EQU/SKL，也不因为播放、搭配或等级选择制造脚本草稿。

## 本版支持范围

## 0.15.16 原包复核

式神玄武可切换空场和擒抱。白虎默认预置一只白虎，施放第二只后展示连锁雷球及其命中，也可单独查看一只白虎的光环。压制符、落雷符和两式神的地面法阵使用 ACT1 的循环帧，持续阶段结束后切入消散。

0.15.17 按 ACT1 目标绘制顺序处理玄武擒抱和松开。黑色底层跟随被擒目标的朝向，玄武本体和亮层随后绘制。不动明王阵的焰珠随轨道深度穿过目标前后，拘束光从地标的第三帧开始。

抛投和满蓄落花掌可切换哥布林撞墙分支。普通枪弹可在对应技能菜单选择左轮弹撞墙。裂波斩以哥布林展示擒抱、升空、下斩和落地。[15 个主动技能的逐项核对](act1-motion-only-audit.md)

冰霜雪人可查看满蓄力首次命中时的冰爆。爆炎弹可切换装填后射击哥布林或墙面的爆炸。强袭流星打在滑行结束时从角色位置播放原版收势冲击。

激光炮基础取枪时长为 299 ms，状态 22 切换枪体并触发枪口环。普通光束在 499 ms 显现，799 ms 开始后坐收枪。未学蓄电和学后短按共用普通光束，各自采用客户端的枪口附加层和后坐参数。满蓄确认光在 1000 ms 出现，预览在确认光结束后的 1150 ms 模拟松键，1350 ms 显现光束，1850 ms 收枪。普通分支与实机录像交叉核对，满蓄分支使用客户端逻辑和原包回放验证。

## 0.15.15 原包复核

五份职业技能表共有 245 个主动条目。分身和弱点感知使用格斗家的状态 10 和增益状态，快速拔枪及移动射击转身使用神枪手射击状态，Ez-8 延迟自爆复用机器人和倒计时图集，炫纹发射及自动炫纹使用已生成炫纹和后续触发的参考场景。这七项都从自动预览播放。

0.15.10 相比 0.15.9 增加 30 项组合预览，其中 28 项此前无自动画面，背摔此前仅动作，杰克爆弹此前只有独立特效。鬼印珠、乱射、黑玫瑰特种战队和天谴飓风等已有部分画面的技能仍缺完整演出。

纯动作技能按说明判断。膝撞、瞬踢和上勾拳可以先核对角色姿态，击退和浮空要有目标。俯冲、摆动、强袭流星打即使有姿态也要核对移动轨迹。被动说明中的派生分支需要从母技能或实战条件查看，例如噬灵鬼斩、雷霆背摔、斗志之歌及命中后生成的炫纹。
