# 加载进度（0.12.2）

打开大 PVF 时，窗口底部显示当前阶段、已处理数量、进度条、已用时间和当前文件。阶段包括工作区识别、目录读取与解密、条目解析、内容及快照校验、草稿载入、标签恢复和文件树整理。

数字是**当前阶段**的进度：读取与校验按实际字节数显示 MiB，条目和文件树按数量显示。阶段切换时重新计数，不将目录完成误当成整个文件加载完成。不知道总量的解密、整理和发现过程使用滚动进度。

资源面板另有独立进度条：先发现 NPK/IMG 文件，再显示已处理包数、当前文件以及包内 IMG 目录条目数，最后整理索引。出现原有索引错误的包也计入已处理数量，保留诊断提示，避免进度一直停在末尾。

打开配置、读取差异、保存草稿和导出等后台操作也显示任务进度；动画帧解码、地图、粒子和副本预览显示独立加载提示。快速预览在 250 ms 内结束时不闪烁。全文搜索显示准备与文件处理进度，编码不兼容、二进制和超大文件被跳过时仍推进处理数量；取消和结果上限保留原有语义。

界面每 100 ms 读取后台线程的最新进度，避免逐条目将更新排入 Swing 队列。任务结束、失败、切换配置或关闭窗口时，清理对应进度；旧任务的迟到回调不能覆盖新任务。

```powershell
python -B tools/check_product.py `
  --product 'pvf-product/build/product/PVFStudio-0.12.2' `
  --archive 'C:\Game\Script.pvf' `
  --npk 'C:\Game\ImagePacks2' `
  --progress-only
```

这是实际加载测试，使用隔离工作区记录进度截图，并检查成功及失败后的进度清理；不执行修改和导出测试。结果写入新建的 `build/product-checks/` 子目录。
