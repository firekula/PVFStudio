# MAP 候选分类和弹窗滚轮：0.14.6

普通候选现在只提供无静态 Boss 怪物配置的 MAP；Boss 候选只提供有 Boss 怪物配置的 MAP。分类读取原生 `[monster]` / 条件怪物记录的角色字段，使用共享 NativeMonsterRecord 边界（包括精英特性、NPC 怪物），不依靠 MAP 名称或 `[type]`。不完整 / 不支持的记录归为 UNKNOWN，不提供为新的候选。已有绑定保留为「已绑定（筛选不符）」，仍可取消，不改写源文件。

分类在现有后台工作队列中执行，按工作区 / 编码缓存不可变原始结果；打开和草稿中的 MAP 始终检查当前文本。未保存的普通→Boss 怪物修改、撤销、保存后草稿与原始恢复不会复用错误缓存。结果检查 catalog signature，避免旧任务覆盖新筛选；分类晚于自动池解析时保留原池以重新交集，用户已修改的选项不被覆盖。
